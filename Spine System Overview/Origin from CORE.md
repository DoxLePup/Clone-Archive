SPINE evolved from an older, more limited system known as CORE (Centralized Operational Replica Engine). CORE was the original platform for managing cloned cognitive functions, but it could only support a single host at a time. It lacked scalability and had no mechanism for preserving or sharing experiences between clones. Its rigidity made it unsuitable for long-term or multi-unit deployment.

DoxLe was the only successful product of CORE. After a catastrophic experiment damaged his DNA sequence, replication became impossible, leaving the project in stasis. Only one surviving DoxLe clone remains.

The breakthrough came through Calypsi, a wolf-dragon hybrid with a mysterious and debilitating curse. In exchange for the lab’s help researching her condition—possibly curing it—she offered her DNA to repair the broken portions of DoxLe’s genetic structure. This act wasn’t selfless; it was a calculated exchange of resources and hope.

The result of this fusion was MawLex, a stable hybrid clone carrying fragments of memory and essence from both DoxLe and Calypsi. MawLex’s creation marked the functional beginning of the SPINE project.

Unlike CORE, SPINE was built to support multiple active clones simultaneously, enabling shared knowledge, cognitive syncing, and full memory preservation even in the event of a clone’s death. It is tailored specifically for the MawLex build and those that follow it. CORE has since been decommissioned, remembered only as the foundation on which the far more advanced SPINE was built.
