# Spine System Overview
### - [[Purpose and design of SPINE]]
Explains what SPINE is built to do, how it functions as a shared cognitive network for clones, and why it was created as an evolution beyond simple memory storage.
### - [[Origin from CORE]]
Covers the transition from the old CORE system to SPINE, including the failure of DoxLe’s replication and how Calypsi’s DNA enabled a stable template that led to the MawLex structure.
### - [[Real-time memory synchronization]]
Describes how clones share experiences and knowledge instantly through SPINE, while still maintaining individual interpretation, reactions, and memory control.
### - [[Max active clone capacity (10)]]
Outlines the hardware-based limit of 10 simultaneously active clones on the SPINE system, and how this cap influences clone replacement, rotation, and emotional weight.
### - [[Non-emotional, non-sensory data sharing]]
Clarifies that while clones can access each other’s memories, they do not feel or sense each other’s emotions or physical sensations—only the data surrounding those experiences.
### - [[Emotional impact of clone death]]
Explores the emotional consequences of a clone dying, the void left in SPINE, how different clones cope, and how memorials help process the loss.
### - [[Network structure, standalone, post-creation connection]]
Details how SPINE operates as a physically isolated system, how clones are only connected after full creation, and why this structure ensures stability, privacy, and ethical control.
